Space Survival

Year 1 · 6G4Z0020 Programming · Don't Crash!! coursework

1. Purpose and tech stack

Space Survival is a 2D arcade survival game in Processing (Java). The ship stays centred; arrow keys shove the whole obstacle field away from the middle. Coloured shapes (circles, squares, triangles) fly in from the edges. The GitHub copy is a re-upload of the Year 1 Programming coursework so it sits on my personal profile.

2. Design

A small state machine drives the sketch: MENU, PLAYING, GAMEOVER. In play, obstacles live in an ArrayList, spawn on a timer, and leave when they exit the screen (scoring a point). Difficulty scales every 20 points via updateDifficulty(), which shortens spawn interval and speeds motion. A hit costs a life, shows an explosion burst, and starts a short invulnerability shield so you are not hit again immediately. 

draw() state machine
  MENU     -> SPACE starts PLAYING
  PLAYING  -> arrows shove field; spawn / move / collide; score + levels
  GAMEOVER -> R restart, M menu

ArrayList<Obstacle> + ArrayList<ExplosionAnimation> / Particle
Player.collision uses dist() vs obstacle radius

3. Features implemented

  • Ship fixed at centre; arrow keys push the obstacle field
  • Five lives shown as hearts; brief shield after a hit
  • Score for each obstacle that leaves the screen; level up every 20 points
  • Obstacles as coloured circle / square / triangle shapes with level-scaled velocity
  • Explosion and particle effects on hit (larger burst on game over)
  • Starfield background; engine flicker and shield visuals on the ship
  • MENU / PLAYING / GAMEOVER with SPACE, R, and M controls
  • Development report PDF in the repo

6. Challenges and how they were handled

ChallengeApproach
Relative motion feels wrong at first Lock the ship to centre; apply opposite deltas to every obstacle on key press
Leaking obstacle objects Remove from the ArrayList when off screen or destroyed
Instant multi-hit after a collision Invulnerability window with a visible shield
Difficulty staying flat updateDifficulty() raises level and shortens spawn interval with score

7. Testing

  • Arrow keys move the field opposite to the press
  • Collision at the expected distance costs a life and shows the shield
  • Obstacles keep drifting with no key held; removed ones leave the list
  • Score and level-up thresholds behave as designed
  • SPACE / R / M move correctly between menu, play, and game over

8. Deployment and links

Install Processing, open Space_Survival.pde (folder name must match), and run. No high-score file between runs; no sound; enemy types stay as coloured shapes rather than sprites. Source and the development report are on GitHub as a personal-profile re-upload.
