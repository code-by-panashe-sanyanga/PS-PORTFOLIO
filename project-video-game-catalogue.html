Video Game Catalogue

Year 2 · 6G5Z0024 ADS · Assessed Exercise 2

1. Purpose and tech stack

Assessed Exercise 2 is a retro gaming preservation catalogue: store games and search them efficiently using binary trees. The brief forbids pre built tree libraries and requires recursion for tree behaviour. Titles are unique keys. The console menu is the operator surface for insert, walk, query, update, and later AVL insert and remove.

LayerChoiceReason
Language C# console Classroom template and recursive tree labs
Domain VideoGame (title, developer, year) Unique title used as the BST key
Structures Node, BinTree, BSTree, then AVLTree Progress from ordered BST to balanced AVL with rotations

2. Design

Task A wires insert into a BSTree and exposes InOrder, PreOrder, and PostOrder from BinTree so the operator can choose a walk. Earliest release year and height are recursive queries; height is node based as specified in the lectures. Task B adds count, update by title (same navigation pattern as insert until the key matches), and list by year. Task C replaces the live structure with an AVL tree: balance factors, rotations on insert, and removal that covers the three classical cases and rebalances afterwards. 

Menu
  -> VideoGame records
  -> BSTree (Tasks A/B): insert, walks, earliest year, height, count, update, by-year
  -> AVLTree (Task C): insert with rotations, remove with rebalance
       LL / LR / RL / RR rotations driven by balance factor

3. Features implemented

  • Insert unique titled games into a BST
  • In / pre / post order listings via the menu
  • Recursive earliest release year and tree height
  • Node count, update in place by title, filter by year
  • AVL insert with rotations when balance breaks
  • AVL remove with restructuring so remaining keys stay reachable
  • Menu switched to drive the AVL structure for Task C

6. Challenges and how they were handled

ChallengeApproach
Everything recursive No iterative shortcuts for walks, height, or count; mirror lecture patterns
Update vs insert Same left/right decisions; on equal title mutate the node instead of inserting
Unbalanced BST degradation AVL balance factor checks and the four rotation cases
Remove without orphaning subtrees Handle leaf, one child, two children; then rotate if unbalanced

7. Testing

  • Insert then InOrder lists titles sorted
  • Duplicate title path updates rather than forking a second key
  • Earliest year matches the minimum release in the set
  • Height and count stay consistent after inserts
  • Year filter returns only that year
  • AVL insert sequence that would skew a BST stays shallow; remove leaves a searchable tree

8. Deployment and links

Console app in the GitHub Classroom repository. Run under Visual Studio or dotnet run. Evidence for the unit is the recursive ADTs and menu coverage of Tasks A to C.
