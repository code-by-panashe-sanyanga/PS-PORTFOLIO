Video Game Catalogue

Year 2 · 6G5Z0024 ADS · Assessed Exercise 2

1. Purpose and tech stack

Assessed Exercise 2 is a retro gaming preservation catalogue: store games and search them efficiently using binary trees. The brief forbids pre built tree libraries and requires recursion for tree behaviour. Titles are unique keys. The console menu is the operator surface for insert, walk, query, update, and later AVL insert and remove.

LayerChoiceReason
Language C# console C# (.NET Framework) console menu for BST / AVL comparison
Domain VideoGame (title, developer, year) Unique title used as the BST key
Structures Node, BinTree, BSTree, then AVLTree Progress from ordered BST to balanced AVL with rotations

2. Design

Task A wires insert into a BSTree and exposes InOrder, PreOrder, and PostOrder from BinTree so the operator can choose a walk. Finding the earliest game means the alphabetically first title (the tree is keyed by title), plus recursive height. Task B adds count, update by title, and list by year. Task C adds an AVLTree that inherits from BSTree and rebalances on insert with the four rotations. The menu can switch between BST and AVL at runtime so you can compare heights on the same data. 

Menu
  -> VideoGame records (keyed by title)
  -> BSTree: insert, walks, earliest title, height, count, update, by-year, remove
  -> AVLTree (extends BSTree): insert with LL / LR / RL / RR rotations
  -> runtime switch between BST and AVL modes

3. Features implemented

  • Insert unique titled games into a BST
  • In / pre / post order listings via the menu
  • Earliest (alphabetically first) game and tree height
  • Node count, update in place by title, filter by year
  • AVL insert with rotations when balance breaks
  • Remove / exists checks from the BST layer
  • Runtime switch between BST and AVL modes

6. Challenges and how they were handled

ChallengeApproach
Everything recursive No iterative shortcuts for walks, height, or count; mirror lecture patterns
Update vs insert Same left/right decisions; on equal title mutate the node instead of inserting
Unbalanced BST degradation AVL balance factor checks and the four rotation cases on insert
Comparing structures Switch BST / AVL at runtime and compare height on the same catalogue

7. Testing

  • Insert then InOrder lists titles sorted
  • Duplicate title path updates rather than forking a second key
  • Earliest game is the alphabetically first title
  • Height and count stay consistent after inserts
  • Year filter returns only that year
  • AVL insert sequence that would skew a BST stays shallow

8. Deployment and links

Re-upload of the ADS coursework on my personal GitHub. Open ADSPortEx2.sln in Visual Studio (F5 / Ctrl+F5), or build with msbuild ADSPortEx2.sln and run ADSPortEx2\bin\Debug\ADSPortEx2.exe. Evidence for the unit is the recursive ADTs and menu coverage of BST versus AVL.
